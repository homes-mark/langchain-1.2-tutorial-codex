011. RAG 不是把全部文档拼进提示词

假设企业有三万份制度文档，而用户只问“年假有多少天”。我们需要先找出相关且有权限阅读的少量片段，再交给生成步骤。这个过程使知识更新不必等待模型重新训练，也使回答能够带来源。RAG 包括检索与生成两部分，向量数据库只是其中一种检索手段。

本章完成索引路径：文档 → 带元数据的 Document → 片段 → 向量 → 索引；提问时则走查询路径：问题 → 查询向量 → 相似度排序 → 候选 Document。下一章才将证据放入提示模板生成回答。现有 SQL、全文检索或业务 API 也可以提供证据，并非所有项目都必须新建向量库。

组件输入 → 输出关键责任
Document文本 + metadata保留来源与权限信息
Splitter长文档 → 多个片段控制片段长度与边界
Embedding文本 → 数值向量建立检索表示
Vector store向量 + 文档 → 候选集存储、筛选与相似度搜索
Retriever问题 → Document 列表为链提供统一检索接口

022. 微型语料与离线向量：先学接口

示例包含 acme 的年假、报销制度，以及 beta 的另一份年假制度。相似主题跨租户存在，能主动暴露权限过滤错误。身份由应用传入，不从用户问题中提取。我们先筛选授权文档再建立租户索引，这使未授权文本不会进入本次生成上下文。

KeywordEmbeddings 为六个固定词统计次数。这是教学用确定性向量，能解释余弦相似度与接口连接，不是训练得到的语义嵌入：“休假”不会自动匹配“年假”，新词可能得到全零向量。示例对全零查询直接返回空结果，避免把任意文档误当成命中。

"""教学 RAG 公用数据。依赖版本见 requirements.lock.txt。

关键词向量只为离线演示检索接口，不是训练得到的语义 embedding。
"""

from langchain_core.documents import Document
from langchain_core.embeddings import Embeddings
from langchain_core.vectorstores import InMemoryVectorStore
from langchain_text_splitters import RecursiveCharacterTextSplitter


class KeywordEmbeddings(Embeddings):
    vocabulary = ("年假", "报销", "住宿", "VPN", "发票", "审批")

    def embed_query(self, text: str) -> list[float]:
        return [float(text.count(word)) for word in self.vocabulary]

    def embed_documents(self, texts: list[str]) -> list[list[float]]:
        return [self.embed_query(text) for text in texts]


DOCUMENTS = [
    Document(
        page_content="年假制度：正式员工每年享有 10 天年假。年假申请应提前 3 个工作日提交，由直属主管审批。",
        metadata={"tenant": "acme", "doc_id": "leave-v1", "source": "员工手册/年假", "version": 1},
    ),
    Document(
        page_content="报销制度：住宿报销上限为每晚 500 元，报销时必须附发票。超额住宿费用需要主管审批。",
        metadata={"tenant": "acme", "doc_id": "expense-v1", "source": "财务制度/住宿", "version": 1},
    ),
    Document(
        page_content="年假制度：另一家公司的年假为每年 30 天。此文档仅属于 beta 租户。",
        metadata={"tenant": "beta", "doc_id": "beta-leave-v1", "source": "Beta 内部手册", "version": 1},
    ),
]


def build_index(tenant: str) -> tuple[InMemoryVectorStore, list[Document]]:
    if tenant not in {"acme", "beta"}:
        raise PermissionError("未知租户")
    # 身份来自应用鉴权层；模型不可自行选择 tenant。先筛选，再建立租户索引。
    permitted = [doc for doc in DOCUMENTS if doc.metadata["tenant"] == tenant]
    splitter = RecursiveCharacterTextSplitter(
        chunk_size=90,
        chunk_overlap=15,
        separators=["\n\n", "\n", "。", "，", ""],
    )
    chunks = splitter.split_documents(permitted)
    for index, chunk in enumerate(chunks):
        chunk.metadata["chunk_id"] = f"{chunk.metadata['doc_id']}:{index}"
    vectorstore = InMemoryVectorStore(KeywordEmbeddings())
    vectorstore.add_documents(chunks, ids=[c.metadata["chunk_id"] for c in chunks])
    return vectorstore, chunks


def retrieve(question: str, tenant: str = "acme", k: int = 2) -> list[Document]:
    embedding = KeywordEmbeddings()
    if not any(embedding.embed_query(question)):
        return []
    # ponytail: 微型语料每次重建；真实服务在启动或索引发布时加载，按租户缓存。
    vectorstore, _ = build_index(tenant)
    hits = vectorstore.similarity_search_with_score(question, k=k)
    return [doc for doc, score in hits if score >= 0.5]


def format_context(documents: list[Document]) -> str:
    return "\n\n".join(
        f"[{doc.metadata['doc_id']}] {doc.page_content}" for doc in documents
    )

运行依赖包括 langchain-core==1.2.5、langchain-text-splitters==1.1.0 和锁定环境中的 NumPy；使用根目录的 依赖锁文件 一次安装。InMemoryVectorStore 的相似度运算需要 NumPy，仅安装 LangChain 主包可能遗漏这个运行时依赖。

033. 切分决定证据是否完整

本例以 90 个字符为上限，并设置 15 字符的目标重叠。字符数不是 token 数，生产端要按实际模型的 tokenizer 和上下文预算另行计算。优先沿段落与中文句号分割，可以减少把条件和结论切开的概率；表格、代码、标题层级适合使用理解对应格式的切分策略。

重叠用于减少边界丢失，但不保证每一对相邻片段都恰好重叠指定长度。过短片段可能丢失适用条件，过长片段会引入无关内容。不要把 90/15 当成最佳参数：为一组真实问答比较不同切分配置的命中情况，再选择。官方递归切分说明介绍了这些参数及中文分隔符设置。

metadata 至少包含稳定 doc_id、source、version 与租户或访问标签。本例 chunk_id 在每次微型索引构建中生成，只适合演示；可增量更新的生产索引应使用文档版本加稳定片段标识，删除旧版本后再发布新版本，防止相互冲突的制度同时被检索。

044. 可运行：先验证检索，再连接模型

从教程根目录运行 python examples/09_rag_index.py。

examples/09_rag_index.py下载源文件 ↗
"""依赖：langchain==1.2.0 / core==1.2.5 / text-splitters==1.1.0。
完整版本见 requirements.lock.txt；运行：python examples/09_rag_index.py。
"""

from rag_support import build_index, retrieve


def main() -> None:
    vectorstore, chunks = build_index("acme")
    retriever = vectorstore.as_retriever(search_kwargs={"k": 1})
    top = retriever.invoke("年假")
    assert top[0].metadata["doc_id"] == "leave-v1"
    assert all(doc.metadata["tenant"] == "acme" for doc in chunks)
    assert all(len(doc.page_content) <= 90 for doc in chunks)
    assert retrieve("火星天气") == []
    assert retrieve("年假", "beta")[0].metadata["doc_id"] == "beta-leave-v1"
    print(f"已建立 acme 索引：{len(chunks)} 个片段")
    print(f"命中文档：{top[0].metadata['doc_id']}")
    print(top[0].page_content)
    print("长度、无匹配查询与租户边界检查：PASS")


if __name__ == "__main__":
    main()

预期输出 已建立 acme 索引：2 个片段、命中文档：leave-v1 以及 PASS。as_retriever(...).invoke(question) 展示 Retriever 接口；共享函数则显式读取相似度分数并过滤低于 0.5 的候选。这两个路径用途不同：前者演示最邻近检索，后者加入本教程的拒答门槛。

0.5 只是这个关键词向量空间中的教学阈值。不同 embedding、向量库和距离类型的分数不可直接比较。换模型或索引参数后必须重新标定阈值。top-k 总能返回“相对最近”的候选，也可能没有一条真正相关；因此不能把返回非空等同于问题可回答。

055. 三档练习与验收

  1. 入门：查询“住宿报销”。验收：第一条是 expense-v1，内容含 500 元与发票要求；查询“火星天气”返回空列表。
  2. 进阶：将年假制度扩展为 200 字以上，同时加入不适用于试用期员工的条款。比较 60、90、150 字符的切分。验收：片段保留 metadata，字符长度受控，并人工检查检索结果是否同时包含天数与适用条件。
  3. 高级：建立至少 12 条检索标注：正常问题、同义问法、跨租户请求、无答案问题各三条。记录 Recall@k（标注相关片段被召回的比例）、跨租户泄漏数、无答案误命中数。验收：跨租户泄漏为 0；记录“休假”失败，解释它暴露的关键词向量局限，而不是修改问题来美化成绩。

066. 换成真实语义检索时保留什么

真实 embedding 模型通过训练学习文本表示，通常比本章词频向量更能处理同义表达。迁移时先确定模型、维度、批量大小和调用预算；文档与问题必须使用同一兼容空间。切换 embedding 模型通常需要全量重建索引，不能把新旧向量直接混放。

生产检索可组合关键词与向量结果，再做重排。权限条件必须由服务端生成，并在返回模型前再次验证；只在前端隐藏引用不够。索引构建通常是独立任务，需要幂等写入、失败恢复、删除传播和版本回滚。本示例每次调用重建两份文档的内存索引，只适合学习；真实服务应加载或复用已发布索引。

不要急于增加向量数据库品牌和多级缓存。先保留可解释的检索测试集，用失败类型决定下一步。完成本章后进入 10 · 检索后生成、引用与拒答。
