01 · 环境、版本与第一次运行

把版本兼容性变成可以检查的事实。先建立隔离环境，再运行一个无需密钥的真实 Agent 图。

入门建议 35 分钟顺序 02 / 22

本章学习目标

  • 理解 langchain、core、provider 与 langgraph 的分工
  • 安装锁定环境并完成导入和运行验证
  • 正确区分离线阅读、离线实验和在线模型

前置知识

Python 基础 · 终端与目录的基本操作

推荐按左侧目录顺序学习；熟悉基础后可从实战阶段一开始。

01选择可复现的版本组合

本教程所说的 LangChain 1.2 指 Python 包 langchain==1.2.0，不是 JavaScript 的同名版本，也不是声称它是当前最新版。Python 官方依赖范围从 3.10 起；本交付实际验证环境为 Windows + Python 3.12.10，推荐按同一主次版本复现。

依赖固定版本作用
langchain1.2.0create_agent 与中间件
langchain-core1.2.5消息、模板、Runnable、工具抽象
langgraph / langgraph-prebuilt1.0.5 / 1.0.5图执行、检查点与工具节点
langchain-openai1.1.6可选的真实模型连接
langchain-text-splitters1.1.0RAG 文本切分
numpy / pygments2.2.6 / 2.19.2本地向量计算 / 构建时高亮

requirements.txt 表达直接依赖；requirements.lock.txt 固定验证环境的全部传递依赖。包版本不要求数字一致：LangChain 与 LangGraph 各自发布。学习时使用锁文件；升级时在新环境重新运行回归，而不是假设一个兼容区间代表所有组合都工作。

02安装与路径约定

以下命令都在解压后的 langchain-1.2-tutorial 根目录执行。路径可按实际位置修改，避免把代码文件命名为 langchain.py 或 openai.py，否则会遮蔽安装包。

powershell
# Windows PowerShell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.\.venv\Scripts\python.exe examples/01_check_environment.py
# 后续命令可继续使用完整 python 路径，无需修改执行策略
bash
# macOS / Linux
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock.txt
python examples/01_check_environment.py

正文为了简洁使用 python examples/...。请先激活环境，或把 python 替换为上面的虚拟环境解释器完整路径。运行脚本时保留整个 examples 目录，因为各文件可能复用 common.py 和 rag_support.py。直接复制单个代码块到别处需要一并复制这些辅助文件。

实际遇到的依赖坑：安装器曾选择 langgraph-prebuilt==1.0.10；pip check 报告正常，但它导入旧 LangGraph 中不存在的 ExecutionInfo，运行即失败。锁定 prebuilt==1.0.5 后导入与执行通过。依赖元数据检查不能代替真实导入测试。

03你的第一个验收脚本

examples/01_check_environment.py下载源文件 ↗
"""Dependency and real import check. Run: python examples/01_check_environment.py"""
from importlib.metadata import version
from langchain.agents import create_agent
from langchain_core.messages import AIMessage
from common import ScriptedChatModel

EXPECTED = {"langchain": "1.2.0", "langchain-core": "1.2.5", "langgraph": "1.0.5",
            "langgraph-prebuilt": "1.0.5", "langchain-openai": "1.1.6",
            "langchain-text-splitters": "1.1.0"}
for name, expected in EXPECTED.items():
    actual = version(name)
    assert actual == expected, f"{name}: expected {expected}, got {actual}"
    print(f"{name}=={actual}")
agent = create_agent(ScriptedChatModel(responses=[AIMessage(content="environment OK")]), tools=[])
assert agent.invoke({"messages": [{"role": "user", "content": "check"}]})["messages"][-1].content == "environment OK"
print("PASS: imports + a real agent graph invocation")

前半段逐一核对核心版本；后半段创建真实 create_agent 执行图，传入一个用户消息，并检查最后一条助手消息。这里的 ScriptedChatModel 只是按预设顺序返回答案的测试替身，因此不需要外部模型。

预期结果：看到六行固定包版本，最后输出 PASS: imports + a real agent graph invocation。如果失败，先检查命令使用的是哪个 Python，再看第一个异常，不要直接升级所有包。库导入失败和服务端 401 属于完全不同的排错层次。

04切换到真实模型

部分脚本提供 --live。共用 common.py 中的 live_model() 从环境读取模型名与密钥，再构造 ChatOpenAI。你需要选择账号实际可用、支持相应工具调用或结构化输出的模型。不同模型能力不同，教程不硬编码未来可能失效的模型名。

powershell
$env:OPENAI_MODEL = "替换为账号可用的模型标识"
# 隐藏输入，避免把密钥明文写入命令历史或教程文件
$credential = Get-Credential -UserName "api-key" -Message "把 API 密钥填入密码框"
$env:OPENAI_API_KEY = $credential.GetNetworkCredential().Password
python examples/07_agents.py --live
Remove-Item Env:OPENAI_API_KEY

这里用到的是显式环境变量，教程不自动读取 .env。真实输出不保证与离线文本一致，应验证有无工具调用、参数是否合规、工具结果是否支撑最终结论。未配置密钥时离线章节仍可全部阅读与运行；交付验证没有请求收费模型 API。

共用连接设置请求超时与有限重试，减少无期限等待。它们不是完整成本上限：工具循环和并发请求还需要 12 的调用预算。若替换其他提供商，单独锁定其适配包，并重新测试消息格式和工具能力。

05在断网环境运行 Python

阅读站点不需安装任何包；执行 Python 需要依赖。可在与目标机器相同操作系统、CPU 架构和 Python 版本的联网机器准备 wheelhouse，再把整个目录复制过去：

bash
python -m pip download -r requirements.lock.txt --only-binary=:all: -d wheelhouse
# 在断网机器的虚拟环境中：
python -m pip install --no-index --find-links=wheelhouse -r requirements.lock.txt
python examples/01_check_environment.py

交付包不包含 wheelhouse，也不包含在线模型权重。固定脚本模型不下载权重；后续的关键词向量器同样在本机计算。跨平台移动 wheelhouse 可能遇到 NumPy 等二进制 wheel 不匹配，不能只看文件数量相同就认为可安装。

06练习与验收

  1. 基础：完成安装并保存校验输出。验收：版本正确且最后一行 PASS。
  2. 进阶：对比 python -m pip check 与环境脚本各证明什么。验收：前者检查依赖声明，后者检查真实导入及一次图执行。
  3. 挑战：制作离线安装包，在新虚拟环境用 --no-index 安装并运行。验收：安装无网络索引访问，Agent 图仍通过；真实模型仍需要联网。

下一章把“消息列表”拆开来看：模型看到的并不是一个随意拼接的字符串，而是带角色和结构的输入。
